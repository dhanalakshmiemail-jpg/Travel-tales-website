Travel Website Frontend Demo
Description

This is a Travel Website Frontend Demo created using HTML and CSS. It is a static sample project that shows a modern travel website design. The project is made for learning frontend web development and adding to a portfolio. It does not include a backend, so all features are for display only.

Features

Responsive homepage design

Navigation bar

Destination cards

Things to Do section

Restaurants section

Hover effects using CSS

Technologies Used

HTML5

CSS3

Purpose

The purpose of this project is to practice website design, page layout, and CSS styling while creating a travel-themed interface.

Project Status

This is a demo project. Booking, login, search, payment, and other interactive features are not functional.
